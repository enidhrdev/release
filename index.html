Pertanyaan Umum

Berapa lama server aktif setelah pembayaran?
Server aktif instan setelah pembayaran terverifikasi di Shopee. Data akses langsung dikirim melalui chat Shopee, biasanya dalam hitungan menit.
Apakah bisa custom nama server dan password?
Ya! Kamu bisa request custom nama server, password, dan beberapa konfigurasi dasar. Hubungi kami via Shopee Chat atau WhatsApp saat melakukan order.
Apa bedanya TeamSpeak3, Mumble, dan TeaSpeak?
TeamSpeak3 adalah standar industri gaming dengan lisensi resmi dan fitur lengkap (32 slot). Mumble adalah alternatif open-source dengan audio jernih tanpa batasan slot. TeaSpeak kompatibel dengan klien TS3 namun mendukung hingga 1024 slot, cocok untuk komunitas besar.
Apakah ada garansi jika server bermasalah?
Ya, kami memberikan garansi dan support teknis. Jika server mengalami gangguan di luar kendali pengguna, kami siap membantu melalui WhatsApp atau Shopee Chat.
Bagaimana cara perpanjang berlangganan?
Kamu cukup melakukan pembelian ulang di toko Shopee kami atau hubungi langsung via WhatsApp untuk perpanjangan. Kami akan memastikan servermu tidak mati saat perpanjangan dilakukan.
